# Canonworks architecture upkeep

For changes to product boundaries, admission or authority rules, schemas, data flows, or shared contracts, read `docs/architecture/current-state.md`, `target-state.md`, and `component-map.md`. Update affected Mermaid nodes and the map in the same change. Mark proposed and implemented behavior separately, with code or design sources, verification, Linear work, and ADR links. Repo docs are authoritative; mirror important changes to Canonworks Notion with the source branch, revision, and content digest. Keep private source material out of diagrams. Run `node scripts/check-architecture.mjs` and the repo's normal checks. Preserve ADR status until the official Notion ledger records a decision. Use [the Canonworks architecture skill](../canon-flow/.agents/skills/canonworks-architecture/SKILL.md) for the detailed workflow when the sibling repo is available.
